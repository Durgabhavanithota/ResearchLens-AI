
# ResearchLens AI

### AI-Powered Research Paper Comparison and Research Gap Detection System Using NLP

ResearchLens AI is a web-based application that analyzes and compares multiple research papers within a selected research area. It extracts important information, identifies potential research gaps, and provides future research recommendations.

## Live Demo

https://researchlens-paper.streamlit.app/

## Features

- Upload multiple research paper PDFs.
- Extract research paper content.
- Analyze objectives, methodology, datasets, results, and limitations.
- Compare research papers using NLP.
- Calculate paper similarity using TF-IDF and Cosine Similarity.
- Identify potential research gaps.
- Generate future research recommendations.
- Visualize comparison results.
- Download research analysis reports as PDF.

## Run Locally

1. Clone the repository:

   `git clone https://github.com/Durgabhavanithota/ResearchLens-AI.git`

2. Open the project folder.

3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run app.py`
